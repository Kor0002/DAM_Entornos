                                        Desarollo de creacion de juego

Para la creacion de un juego por ejemplo uno de futbol de penaltis se crearia los personajes los campos de futbol, las pelotas , porterias , arbitros y diferentes climas. El juego consiste en un jugador que esta a punto de tirar un penalti con una pelota y hay un portero con una porteria detras, el jugador que esta en el punto del area del penalti con una pelota que tiene una flecha que vaya de lado a lado y tendra que darle en el momento adecuado para meter el gol y asi hasta meter 5 goles seguidos. Si el portero para mas de la mitad o la mitad el jugador pierde la partida y tendra que volver a empezar desde cero. El juego antes de empezar tendra un menu donde ponga jugar , elegir jugador e elijir pelota tambien dentra unos ajustes de volumen y de dificultad.
El juego se guardaria en una carpeta con el nombre de juego donde abria varios archivos dentro como el index.html con conexiones a otras carpteas como el Javascript o el CSS+.

1.1  Problema

Las limitaciones de este juego seria los personajes que se quedan pillados o que no aparezca la pelota el portero que no se mueva o que no se lance a ningun lado tambien podria suceder que la flecha no se mueva o que no aparezca. Tambien podria pasar que el sonido no se reproduciria. En el menu podria fallar y que no aparezca los ajustes o los botones.

2.0 Algoritmos 

Los algoritmos que utilizaria seria el del contador de goles seria int goles = 0; y que haya una funcion que se valla sumando cada vez que meta un gol. 

3.0 Como se llegaria a ejecutarse 

El juego estaria en un host de web donde estaria la carpeta del juego con los diferentes archivos del juego. Una vez que entres en el enlace de juego aparecera un menu donde estara las opciones para iniciar el juego.
